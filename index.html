Is this port actually reachable?

ss, ufw status, and docker ps each only partially answer that. SentryGrid correlates all three — because Docker inserts its own iptables rules ahead of ufw's, a port can be wide open on the LAN while ufw reports nothing wrong at all.

How it classifies

SAFE

Bound to loopback only — not reachable from anywhere else on the network.

BLOCKED

Bound wide, but ufw's default-deny has no matching rule — currently unreachable.

EXPOSED (ufw-allowed)

Bound wide, ufw has an unrestricted ALLOW IN rule — reachable from anywhere.

EXPOSED (ufw-scoped)

Bound wide, ufw's rule is scoped to a specific address — reachable, but only from that scope.

EXPOSED (docker)

Bound wide and Docker-managed — reachable regardless of what ufw says.
